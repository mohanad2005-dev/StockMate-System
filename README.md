# 📦 StockMate

**Simple Inventory Management System**

StockMate is a simple desktop application built with C# and Windows Forms to help users manage inventory through a clean, modern, and user-friendly interface.

## ✨ Features

- 📦 Inventory management
- 🖥️ User-friendly Windows Forms interface
- 🎨 Modern and simple design
- 🌿 Clean green-and-white color scheme
- ℹ️ About screen with application information

## 🛠️ Technologies Used

- **Language:** C#
- **Framework:** Windows Forms
- **IDE:** Visual Studio

## 🚀 Getting Started

### Prerequisites

Before running StockMate, make sure you have:

- Windows operating system
- Visual Studio installed
- The .NET framework or runtime required by the project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohanad2005-dev/StockMate-System.git
   ```

2. Open the project folder.
3. Open `StockMate.sln` in Visual Studio.
4. Restore the required dependencies, if needed.
5. Build and run the project.
